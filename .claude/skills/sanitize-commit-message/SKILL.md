# Sanitize commit message attribution

Rewrites `COMMIT_MESSAGE.txt` at the repo root so it contains no reference
to Claude, Anthropic, or any contributor other than the current human git
user — just the commit message itself, attributable solely to them. This
skill never runs `git add`, `git commit`, or `git push`, and never touches
`.gitignore` or any other file.

## Steps

1. Confirm `COMMIT_MESSAGE.txt` exists at the repo root. If it doesn't, tell the user and stop — don't create one (that's the companion `commit-message` skill's job).

2. Determine the current human user's identity: `git config user.name` and `git config user.email`. This is who attribution is allowed to remain for.

3. Read the file and remove:
   - Any **trailer line** matching `Co-Authored-By:`, `Signed-off-by:`, `Reviewed-by:`, `Generated-by:`, or similar `Key: Name <email>` trailer conventions, **unless** the name/email on that line matches the current human user from step 2. This includes but is not limited to AI trailers — any second author/reviewer/co-signer is "someone other than the current human user" per the request, so it goes too.
   - Any line or inline clause naming **Claude**, **Anthropic**, or a Claude model name (Sonnet, Opus, Haiku, Fable), including domains like `anthropic.com` or `claude.com`.
   - Any AI-generated-content footer, e.g. lines like `🤖 Generated with [Claude Code](...)` or "Generated by Claude" / "Co-written by Claude" phrasing, whether they're a standalone trailer line or folded into a sentence.
   - If removing a clause leaves an awkward sentence fragment (e.g. "Implemented with help from Claude." as a whole sentence in the body), remove the whole sentence rather than leaving a dangling fragment — don't rewrite/paraphrase the rest of the message otherwise.

4. Collapse any blank-line artifacts left behind by the removals (e.g. a trailing blank line where a trailer used to be, or a doubled blank line) so the result still reads as a normal, cleanly formatted commit message — summary line, blank line, body — with no dangling whitespace at the end.

5. If nothing in the file actually needed removal, say so and leave the file untouched (don't rewrite it just to rewrite it).

6. Otherwise write the cleaned message back to `COMMIT_MESSAGE.txt` (Edit, not a full Write, so only the actual attribution lines change) and report back concisely what was removed (e.g. "removed the Co-Authored-By: Claude Sonnet 5 trailer").
